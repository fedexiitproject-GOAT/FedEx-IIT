Odoo 18 Community Edition

FedEx Data Repository

Enterprise research and project data repository with expanded multi-centre taxonomy, end-to-end document verification checklists, fine-grained access control, and real-time liquid-glass analytics dashboards.

Key Capabilities

01

Unified Identity Model

Extends res.partner with dedicated _inherits profiles for Students, Faculty, and Staff, ensuring clean contact integration without identity fragmentation.

02

Document Lifecycle & Versioning

Multi-scope documents (Person, Project, Engagement) with automated replacement wizards, chatter audits, version archival, and compliance checklists.

03

Granular Multi-Tier Security

Independent role groups (Admin, Repository Manager, Centre Coordinator, Faculty, Student, Read-only Management) with strict centre-scoped record rules.

04

Two-Phase Excel/CSV Importer

Robust batch data onboarding with sample template generation, dry-run validation preview, row-level error reporting, and duplicate handling.

05

Liquid-Glass Dashboard

Modern OWL client action dashboard offering interactive KPI cards, live document health indicators, global search, and responsive data visualization.

06

Automated Audit Alerts

Cron-based monitor tracking nearing-completion projects, overdue milestones, missing prerequisite documents, and expired member engagements.

Technical Specifications

  • Target Platform: Odoo 18.0 Community / Enterprise
  • Python Compatibility: Python 3.10+ (Tested on Python 3.12)
  • External Dependencies: openpyxl (for XLSX import templates and parsing)
  • License: GNU Lesser General Public License v3.0 (LGPL-3)
  • Included Centres: IIT Bombay FedEx ALFA, IIT Madras FedEx SMART

Installation

# 1. Ensure openpyxl is installed
pip install openpyxl

# 2. Add fedex_repository to your addons-path and update apps
odoo-bin -c /path/to/odoo.conf -u fedex_repository --stop-after-init
