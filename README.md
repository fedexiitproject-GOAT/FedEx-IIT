### FedEx Data Repository for Odoo 18

FedEx Data Repository (`fedex_repository`) is an enterprise-grade Odoo 18 Community addon engineered for multi-centre academic and industrial research collaborations (including IIT Bombay FedEx ALFA and IIT Madras FedEx SMART). 

**Key Highlights:**
- **Unified Identity:** Extends `res.partner` using delegation inheritance (`_inherits`) for Students, Faculty, and Staff.
- **Document Vault:** Three-tier scoping (Person, Project, Engagement) with automated versioning, replacement wizards, and compliance checklists.
- **Two-Phase Importer:** Safe batch onboarding for CSV & Excel (XLSX) with dry-run preview, downloadable error reporting, and duplicate policies (`skip` / `update`).
- **Granular Security:** Independent role-based access control (Admin, Repository Manager, Centre Coordinator, Faculty, Student, and Read-Only Management) with strict centre-level data segregation.
- **Interactive OWL Dashboard:** Responsive liquid-glass UI with live KPI counters, audit health alerts, and instant global search.
